| File | Product |

| `2.jpg` | Rangoli Color Kit |
| `3.jpg` | Sparkler Pack |
| `4.jpg` | Festive Sweet Hamper |
| `5.jpg` | Golden Lantern |

**Supported formats:** `.jpg`, `.jpeg`, `.png`, `.webp`
(If you use a different format, update the `image` path in `lib/data.ts` accordingly.)

Until images are placed here, a purple placeholder with a photo icon will be shown.
